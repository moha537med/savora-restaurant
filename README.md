# 🍽️ Savora Restaurant

A modern, responsive restaurant website built with **HTML, CSS, and Vanilla JavaScript**.

## 🌐 Live Demo

[View Live Website](https://moha537med.github.io/savora-restaurant/)

## ✨ Features

* Fully responsive design
* Multi-page website
* Mobile hamburger navigation
* Dynamic menu with category filtering
* Limited-time offers with countdown timer
* Shopping cart with quantity controls
* Cart data saved using `localStorage`
* Table reservation form with validation
* Date and opening-hours validation
* Character counter for special requests
* Dynamic image gallery with modal
* Customer reviews slider
* Animated statistics counter
* Scroll reveal animations
* Contact form validation
* SEO-friendly structure and optimized images

## 🛠️ Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* ES Modules
* LocalStorage
* Git & GitHub
* GitHub Pages
